# basildom

Basildom is a learning-oriented toy browser engine written in TypeScript.
It explores how modern browsers parse HTML and CSS, construct a DOM, compute layout, and render content to a simplified output.

## Motivation
The goal of this project is to gain a deeper understanding of how real-world browser engines work internally.

## High-Level-Architecture
### implemented
1. HTML-Parser
2. CSS-Parser
### will be implemented
3. Style mapping
4. Simple canvas rendering

## Deliberate Simplifications
This project excludes several aspects in order to keep it simple.
Among other things, don't expect:
- JavaScript support
- Advanced CSS features
- Groundbreaking performance
